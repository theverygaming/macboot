# littleboot
Bootloader for m68k Macintosh and [funnyarch](https://github.com/theverygaming/funnyarch) with a boot protocol strongly inspired by [the Limine Boot Protocol](https://github.com/Limine-Bootloader/limine-protocol/blob/3a0526b700e356f0eac1b71a77697b3fd1c707a3/PROTOCOL.md).

Originally created to boot [vix](https://github.com/theverygaming/vix) on m68k Macintosh
